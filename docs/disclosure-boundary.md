# Disclosure Boundary

## L0 Public GitHub

Show only a simplified UI shell, public API contracts, bounded PASS / REVIEW /
HOLD examples, and product wording.

Do not include source candidates, full Body Fit ID formulas, calibration
coordinates, raw vectors, scoring weights, prompt packets, YouCam task IDs, API
keys, or private QA logs.

## L1 Judge Staging

The judge URL may be access controlled. Provide judge-only credentials in the
competition testing instructions and rotate them after review.

## L2 Internal Admin

Calibration dragging, PNG restore, full QA matrices, and decode tools belong in
internal admin mode.

## L3 Private Evidence

Generation repair history, raw candidates, external-review notes, and dispatch
ledgers stay private.

## L4 Secrets

Environment variables, password hashes, API keys, provider credentials, and
cookie secrets are never committed.
